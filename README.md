# Cross-Platform Chat Application (Qt/QML)

Простое приложение для чата между двумя пользователями, реализованное на C++ и Qt/QML. Проект демонстрирует работу с сокетами (WinSock2), многопоточность и создание современного интерфейса на QML.

## Особенности
- **Архитектура Клиент-Сервер:** Раздельная логика для хоста (Server) и гостя (Client).
- **Современный интерфейс:** Безрамочное окно (Frameless) с кастомным дизайном, тенями и закругленными углами.
- **Real-time связь:** Мгновенная передача сообщений по протоколу TCP.
- **Поддержка туннелирования:** Код адаптирован для работы через внешние сервисы (Pinggy, Ngrok) для общения через интернет.
- **Безопасность потоков:** Использование `std::mutex` для предотвращения конфликтов при одновременном доступе к сокету из разных потоков.

## Технические детали
- **C++ Backend:** Обработка низкоуровневых сокетов и сигналов.
- **QML Frontend:** Динамический интерфейс с использованием ListModel и делегатов для отображения сообщений.
- **Сетевой порт:** По умолчанию используется порт `49152`.

## Как запустить
1. Откройте проект в **Qt Creator**.
2. Переключитесь в режим **Release** для оптимальной работы.
3. Соберите проект (Build).
4. Если вы используете Pinggy или ngrok, обновите `pinggy_host` и `pinggy_port` в `GuestBackend.h` данными из терминала.

## Развертывание (Deploy)
Для создания переносимой версии (чтобы работало у друга без Qt):
1. Используйте `windeployqt --qmldir <путь_к_исходникам> Project.exe`.
2. Передавайте `.exe` вместе со всеми созданными `.dll` и папками.
